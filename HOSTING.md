# Размещение вне Vercel

Проект можно запустить как обычное Node.js-приложение или Docker-контейнер.

- Node.js 24, установка: `npm install --omit=dev`, запуск: `npm start`.
- Порт берётся из `PORT`, по умолчанию 3000.
- Для Timeweb Cloud App Platform можно выбрать Backend / Dockerfile и подключить этот репозиторий.
- Для нового размещения нужен HTTPS: сессионная cookie имеет флаг Secure.
- Настройки задаются только через переменные окружения сервиса: `BLOB_READ_WRITE_TOKEN`, `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`. Не добавляйте их в GitHub или Dockerfile.
- Каталог, пароль администратора после смены и фото пока остаются в существующем закрытом Vercel Blob. Они не хранятся на временном диске контейнера и не стираются при перезапуске.
- Браузер обращается к новому хостингу; чтение Vercel Blob выполняет сервер. Доступ к Blob с нового сервера нужно проверить перед переключением сайта. Если недоступен, потребуется перенос данных и фото в другое постоянное хранилище, например S3.

## Что уже проверено по старому адресу

15 октября 2026 сайт отвечал HTTP 200 из одной московской сети, Санкт-Петербурга и Германии. Из другой московской сети — тайм-аут при корректном DNS. Альтернативный домен Vercel также дал тайм-ауты в части сетей.

Это указывает на зависимость доступа от сети/маршрута. Новое размещение нельзя считать исправлением до проверки главной страницы, каталога, фото и админки без VPN именно в сети владельца.

## Несколько фотографий

У товара может быть до 10 фотографий. В админке можно загрузить несколько файлов, выбрать главное фото и убрать снимок из карточки. Каждый файл — JPG, PNG или WebP до 3 МБ. Старое одиночное поле `photo` поддерживается; главное фото сохраняется в нём для совместимости.
